📚 Integration Guide

This visualization is powered by a modular JavaScript file that can be embedded anywhere:

<!-- 1. Include D3.js -->
<script src="https://d3js.org/d3.v7.min.js"></script>

<!-- 2. Include the CSS Code Viz module -->
<script src="css_code_viz.js"></script>

<!-- 3. Render in your application -->
<script>
  // Initial render
  CSSCodeViz.render('#main-visualization');

  // Highlight errors on specific qubits
  CSSCodeViz.highlightErrors('#main-visualization', ['q0', 'q5']);

  // Toggle edge types
  CSSCodeViz.toggleEdges('#main-visualization', 'x_check', false);
</script>

Features: Error highlighting, edge toggling, custom styling, dynamic updates
